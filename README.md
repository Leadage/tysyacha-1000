# Тысяча (1000) — браузерная реконструкция

Карточная игра «Тысяча» в стиле классической Windows-программы конца 90-х.
Человек играет против двух (или трёх) компьютерных соперников.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # сборка в dist/
npm test         # unit- и интеграционные тесты движка
```

## Архитектура

Логика игры полностью отделена от React — движок не импортирует ни одного
компонента и работает как чистый конечный автомат.

```
src/
  game/
    cards.ts        колода, старшинство, стоимость
    deck.ts         раздача 7+7+7+3
    rng.ts          детерминированный ГПСЧ с сериализуемым состоянием
    settings.ts     все договорённости + метаданные для окна настроек
    bidding.ts      торговля, ограничение по марьяжам, молчание
    marriages.ts    марьяжи, тузовый марьяж, бонус сидящего на прикупе
    legalMoves.ts   обязательная масть, обязательный козырь, объявление марьяжа
    scoring.ts      округление до пяти, порог победы
    barrel.ts       расчёт кона: роспись, удвоения, болты, бочка, самосвал
    ai.ts           компьютерные игроки (knowledge state без скрытой информации)
    gameEngine.ts   конечный автомат и reducer действий
    gameState.ts    типы состояния, событий и истории
    persistence.ts  localStorage
    stats.ts        статистика
    sound.ts        WAV-файлы либо синтез WebAudio
  components/       Win98-виджеты, карты (SVG), таблицы, диалоги, debug-панель
  screens/          игровой стол
  styles/           win98.css, game.css
  tests/            83 теста правил и полные партии
```

Состояния автомата: `SETUP → DEALING → REDEAL_DECISION → DARK_GAME_DECISION →
BIDDING → TALON_REVEAL → TALON_REDEAL_DECISION → DISCARDING → FINAL_CONTRACT →
PLAYING_TRICK ⇄ TRICK_RESULT → ROUND_SCORING → ROUND_END → GAME_OVER`.

## Ассеты

| Куда положить | Что |
|---|---|
| `public/characters/player.png` | портрет игрока (внизу слева) |
| `public/characters/left.png` | левый соперник |
| `public/characters/right.png` | правый соперник |
| `public/characters/fourth.png` | третий бот (режим на 4 игроков) |
| `public/sounds/card.wav` | положили карту |
| `public/sounds/marriage.wav` | объявили марьяж |
| `public/sounds/trick.wav` | забрали взятку |
| `public/sounds/message.wav` | сообщение / ставка |
| `public/sounds/wakeup.wav` | сигнал |

Файлов может не быть: тогда рисуются силуэты и играют синтезированные бипы,
разметка экрана не меняется.

Референсные скриншоты оригинала лежат в `reference/`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F2` | новая партия |
| `Esc` | спрятать игру (подменяет заголовок вкладки и favicon), повторно — вернуть |
| `Ctrl+Shift+D` | отладочная панель |

## Обозначения в таблице счёта

`Z` — самосвал, `D` — двойной результат, `R` — роспись, `O` — сброс после трёх
бочек, `-` — болт, `!` — штраф за болты, `#` — сидел на прикупе, `B` — сел на
бочку, `↓` — слёт с бочки со штрафом.
